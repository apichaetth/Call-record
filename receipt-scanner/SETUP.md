# POCO ใบเสร็จ — คู่มือติดตั้ง

เว็บแอปสำหรับ iPhone (เปิดใน Safari แล้วเพิ่มไปยังหน้าจอโฮม) ใช้ถ่ายหรือสแกนใบเสร็จ อ่านยอดอัตโนมัติ (OCR ภาษาไทย+อังกฤษ) แปลงรูปเป็น JPG แล้วอัปโหลดขึ้น **pCloud** โดยแยกโฟลเดอร์ตามเดือน

## ใช้ทำอะไรได้บ้าง

| โหมด | การทำงาน |
|---|---|
| 📷 ถ่ายรูปใบเสร็จ | เปิดกล้อง ถ่ายแล้วแอปอ่านยอดและส่งขึ้น pCloud ทันที (ปิดการส่งอัตโนมัติได้ในตั้งค่า) |
| 🖼️ สแกนบิลจากอัลบั้ม | เลือกรูปบิลที่มีอยู่แล้วในเครื่องได้หลายใบ อ่านยอด ตรวจและแก้ข้อมูล แล้วกดส่ง |

- ข้อมูลที่อ่าน: ร้าน/ผู้ขาย, วันที่ (รองรับ พ.ศ.), ยอดรวม, VAT, เลขผู้เสียภาษี 13 หลัก, เลขที่บิล แก้ไขได้ทุกช่องก่อนส่ง
- ที่เก็บใน pCloud: `/ใบเสร็จ/2026-11/2026-11-20_ชื่อร้าน_1284.00บาท_ab12.jpg` (เปลี่ยนโฟลเดอร์หลักได้ในตั้งค่า)
- ปุ่ม **สรุป CSV**: ส่งออกตารางรายการทั้งหมดในแอป (วันที่ ร้าน ยอด VAT เลขผู้เสียภาษี เลขที่บิล ชื่อไฟล์) เปิดใน Excel ได้ภาษาไทยไม่เพี้ยน
- รูปจาก iPhone (.HEIC) จะถูกแปลงเป็น .JPG ให้อัตโนมัติ
- ถ้าเน็ตหลุดหรือยังไม่ได้เข้าสู่ระบบ รายการจะค้างไว้ในเครื่อง ส่งทีหลังได้ด้วยปุ่ม "ส่งที่ค้างทั้งหมด"
- ปุ่ม "บันทึกรูป" เปิดเมนูแชร์ของ iPhone เพื่อบันทึก JPG ลงอัลบั้มหรือแอปไฟล์
- **POCO System:** ยังไม่ได้เชื่อมต่อ รอข้อมูลการเชื่อมต่อก่อน (โค้ดจุดเชื่อมต่อคือ `sendToPoco()` ใน `app.js`)
- **NAS (QNAP):** แอปนี้ไม่ได้ใช้ NAS

## ขั้นที่ 1 — เปิดเว็บด้วย GitHub Pages

1. ไปที่ repo `apichaetth/call-record` บน GitHub แล้วเปิด **Settings → Pages**
2. ตรง **Source** เลือก *Deploy from a branch*
3. เลือก branch ที่มีโฟลเดอร์ `receipt-scanner` (เช่น `main` หลัง merge) และโฟลเดอร์ `/ (root)` แล้วกด **Save**
4. รอ 1–2 นาที แอปจะอยู่ที่
   `https://apichaetth.github.io/call-record/receipt-scanner/`

> ถ้า repo เป็น private, GitHub Pages ต้องใช้แพ็กเกจ GitHub Pro/Team ขึ้นไป หรือจะย้ายโฟลเดอร์นี้ไปไว้ใน repo สาธารณะแยกต่างหากก็ได้ ในโค้ดไม่มีรหัสลับใดๆ เพราะ Client ID ใส่ในหน้าตั้งค่าของแอปแต่ละเครื่อง

## ขั้นที่ 2 — ลงทะเบียนแอปกับ pCloud (เอา Client ID)

ใช้บัญชี pCloud ที่จะเก็บใบเสร็จ

1. เข้าสู่ระบบ pCloud บนคอมพิวเตอร์ แล้วเปิดหน้า **My applications** ของ pCloud สำหรับนักพัฒนา: <https://docs.pcloud.com/my_apps/>
2. กดสร้างแอปใหม่ ตั้งชื่อเช่น `POCO ใบเสร็จ`
3. ถ้ามีให้เลือกสิทธิ์ ให้เลือกแบบเข้าถึงไฟล์ทั้งหมดและเขียนไฟล์ได้ (ถ้าเลือกแบบโฟลเดอร์เฉพาะแอป ไฟล์จะไปอยู่ในโฟลเดอร์ของแอปที่ pCloud สร้างให้แทน)
4. ช่อง **Redirect URI** ใส่ลิงก์แอปจากขั้นที่ 1 ให้ตรงทุกตัวอักษร รวม `/` ท้าย:
   `https://apichaetth.github.io/call-record/receipt-scanner/`
5. บันทึก แล้วคัดลอก **Client ID** ไว้ (ไม่ต้องใช้ Client Secret)

> การเข้าสู่ระบบแบบนี้แอปไม่เห็นรหัสผ่าน pCloud และสิทธิ์ไม่หมดอายุเอง ล็อกอินครั้งเดียวต่อเครื่อง ยกเลิกได้ด้วยปุ่ม "ออกจากระบบ" ในแอป หรือยกเลิกสิทธิ์ของแอปในหน้าตั้งค่าบัญชี pCloud
>
> ขั้นตอนบนเว็บ pCloud อาจเปลี่ยนชื่อเมนูได้ ถ้าหาไม่เจอให้ค้นคำว่า "pCloud API My applications"

## ขั้นที่ 3 — ติดตั้งบน iPhone

1. เปิดลิงก์จากขั้นที่ 1 ใน **Safari** (ไม่ใช่ Chrome หรือ LINE)
2. กดปุ่มแชร์ ⬆︎ → **เพิ่มไปยังหน้าจอโฮม**
3. เปิดแอปจากหน้าจอโฮม แล้วกด ⚙︎
   - วาง **pCloud Client ID**
   - ตั้ง **โฟลเดอร์ใน pCloud** (ค่าเริ่มต้น `/ใบเสร็จ` ใส่ซ้อนได้ เช่น `/บัญชี/ใบเสร็จ`)
   - กด **ทดสอบ** แอปจะพาไปหน้าเข้าสู่ระบบ pCloud กดอนุญาตแล้วจะกลับมาที่แอปเอง
   - กด ⚙︎ → **ทดสอบ** อีกครั้ง ควรขึ้น ✓ พร้อมใช้ และอีเมลบัญชี pCloud
   - กด **บันทึก**
4. ครั้งแรกที่อ่านใบเสร็จ แอปจะโหลดข้อมูลภาษาไทยประมาณ 10–15 MB ครั้งต่อไปจะเร็วขึ้น

## ปัญหาที่พบบ่อย

| อาการ | วิธีแก้ |
|---|---|
| pCloud แจ้งว่า redirect_uri ไม่ถูกต้อง | Redirect URI ในขั้นที่ 2 ต้องตรงกับลิงก์แอปทุกตัวอักษร รวม `/` ท้าย |
| เข้าสู่ระบบแล้วไม่กลับมาที่แอปหน้าจอโฮม | เปิดแอปผ่าน Safari แล้วเข้าสู่ระบบครั้งแรกที่นั่น จากนั้นค่อยใช้จากหน้าจอโฮม |
| "ต้องเข้าสู่ระบบ pCloud ใหม่" | สิทธิ์ถูกยกเลิกหรือเปลี่ยน Client ID กด "เข้าสู่ระบบ pCloud" อีกครั้ง รายการที่ค้างจะส่งให้เอง |
| อ่านยอดผิด | ถ่ายให้ตรง สว่าง และเห็นทั้งใบ หรือแก้ตัวเลขในช่องก่อนกดส่ง |

## ไฟล์ในโฟลเดอร์นี้

| ไฟล์ | หน้าที่ |
|---|---|
| `index.html`, `styles.css` | หน้าจอแอป |
| `app.js` | กล้อง/อัลบั้ม, แปลง JPG, คิวในเครื่อง (IndexedDB), เข้าสู่ระบบ pCloud, อัปโหลด, สรุป CSV |
| `ocr-parse.js` | แยกยอด/วันที่/เลขผู้เสียภาษี/เลขที่บิลจากข้อความ OCR |
| `sw.js`, `manifest.json`, `icons/` | ทำให้ติดตั้งบนหน้าจอโฮมและเปิดได้เร็ว |
